# drakx — сайт

Лендинг: сайти й Telegram-боти для СТО та малого бізнесу.
Живе тут: https://ddrakkx.github.io/drakx/ (GitHub Pages, гілка `main` — що запушив, те й на сайті за 1–2 хв).

## Посилання для холодних повідомлень

Давай посилання на сторінку ніші: у неї свій заголовок, тексти й **своє превʼю в Telegram/Viber**.

- `?v=pro` до будь-якого посилання — картка «Кілька точок» у цінах стає першою й підсвічується (для мереж).
- Старі посилання `?n=beauty` теж працюють, але превʼю в месенджері в них загальне: месенджери не виконують JS.
- Telegram кешує превʼю. Якщо змінив картинку чи заголовок — надішли посилання боту [@WebpageBot](https://t.me/WebpageBot), він оновить.

## Що де лежить

```
index.html            уся сторінка: HTML, CSS і JS в одному файлі
beauty/ clinic/ …     сторінки ніш — ГЕНЕРУЮТЬСЯ, руками не правити
demo/<slug>/          демо-сайти для ніш (по два на нішу), кожен — один index.html + img/ + images.json (промпти фото)
media/                скриншоти робіт, каркаси для лінзи (*-x-*), превʼю og*.jpg
fonts/                Inter, обрізаний до символів сайту
tools/                скрипти нижче
sitemap.xml robots.txt  генеруються разом зі сторінками ніш
```

## Після кожної зміни index.html

```bash
python3 tools/make_niches.py
```

Перезбирає сторінки ніш, `sitemap.xml` і `robots.txt`. Без цього на `/beauty/` та інших лишиться старий текст.

Подивитись локально: `python3 -m http.server 8787` і відкрити http://localhost:8787

## Скрипти

| Скрипт | Що робить | Потрібно |
|---|---|---|
| `tools/make_niches.py` | сторінки ніш + sitemap/robots | лише Python |
| `tools/make_og.py` | превʼю посилань 1200×630: `media/og.jpg` і `media/og-<ніша>.jpg` з шаблону `tools/og.html` | `pip install playwright pillow` і `playwright install chromium` |
| `tools/make_media.py` | новий кейс: скриншот → `media/<назва>-720/1440.webp` + сірий каркас для лінзи | `pip install pillow` |
| `tools/make_fonts.py` | обрізає Inter (повні файли — в історії git, команда в самому скрипті) | `pip install fonttools brotli` |
| `tools/gen_photos.py` | фото для демо за `demo/*/images.json` через Gemini API (ключ у `~/.gemini-key`). На безкоштовному ключі картинок немає: фото робили в AI Studio вручну | `pip install pillow` |

## Демо-сайти для ніш

На сторінках ніш у «Роботах» спершу два демо цієї ніші, потім реальні кейси. Що показувати, задає `tools/demos.json`:
назва, вид бізнесу, місто, одне речення «що можна спробувати» і `mh` (висота мобільного знімка). Перше демо ніші ще й гортається в телефоні в картці «Сайти».
Знімки демо: `media/demo-<slug>-720/1440.webp` (перший екран 1440×900) і `media/demo-<slug>-m-360/480/720.webp` (телефон, лише для першого демо ніші).

Демо чесні: угорі плашка «Демо-сайт від drakx», бізнес вигаданий, без відгуків, рейтингів і телефонів, `noindex`.

## Як змінити тексти під ніші

Усі тексти ніш — в обʼєкті `NICHE` у JS наприкінці `index.html`: надзаголовок `k`, заголовок `h1`, тип бізнесу `biz` (для готового тексту в Telegram), сповіщення острова `t`/`s`, блок «Навіть уночі» `d1`/`d3t`/`d3`, приклад чату з ботом `ch`.

Нова ніша = запис у `NICHE` + рядок у `META` в `tools/make_niches.py` + запис в `OG` у `tools/og.html`, потім обидва скрипти.

## Неочевидні речі (щоб не зламати)

- **Шрифти.** При обрізанні Inter не викидати хінтинг (таблиці `prep`/`gasp`), інакше в Chromium на Linux «т» розсувається: «клієнт ський». Символу, якого немає у шрифті (₴, →, ≈), браузер підставить системний — додай його в `tools/make_fonts.py` і в `unicode-range` в `index.html`.
- **Рідке скло** (заломлення країв меню, острова, кнопок, лінзи) працює лише в Chromium; Safari й Firefox показують звичайне матове скло. Сила ефекту — у JS-списку `list`: `s` — наскільки гне, `b` — ширина краю.
- **`overflow-x: clip`, а не `hidden`** на `html`/`body`: `hidden` ламає `position: sticky` (липкі картки й етапи в «Як я працюю»).
- **Тире.** Нерозривний пробіл ставимо *перед* тире (`самі&nbsp;— навіть`), щоб рядок не починався з тире.
- **Переписка в «Як я працюю»** йде за часом (~8 с), щойно чат з'явився; кроки, які вже прогорнули, показуються одразу. Переписка ілюстративна, не реальний клієнт.
- **Живий лічильник Gold Auto** у кейсі бере цифри з `https://goldauto.online/api/shop/bot-stats` (бот оновлює їх раз на 5 хв). Якщо сервер мовчить, лишаються останні відомі цифри, вписані в розмітку `#bstats`, — час від часу онови їх руками.
- **Анімації** поважають «зменшити рух» і «зменшити прозорість» у системі — при змінах перевіряй обидва режими.
